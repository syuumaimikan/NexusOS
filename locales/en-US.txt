# NexusOS — English (United States)
#
# One `key = value` per line. Blank lines and lines beginning with `#` are
# ignored. Values are UTF-8 and may contain `{name}` placeholders, which the
# kernel substitutes at runtime.
#
# Placeholders exist so that translations can reorder them. `value.memory` puts
# the free figure first in English and the total first in Japanese; a
# positional format string could not express that.
#
# Serial-log messages are deliberately NOT translated. They are a developer
# interface, they need to stay greppable, and a bug report is far more useful
# when its log reads the same everywhere.
